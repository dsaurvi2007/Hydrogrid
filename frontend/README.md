# HYDROGRID Frontend

The HYDROGRID frontend is a responsive React and TypeScript application built with Vite.

## Development

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

The frontend is available at `http://127.0.0.1:5173`.

## Routes

- `/` — Overview
- `/login` — Role-based demonstration login
- `/roles` — Role workspaces
- `/admin` — Admin dashboard
- `/owner` — Tubewell Owner dashboard
- `/farmer` — Farmer dashboard
- `/modules` — AI, IoT, digital twin, maintenance, and weather demonstrations

## Validation

```powershell
npm run lint
npm run build
npm run preview
```
